# 📄 GitHub

- **Catégorie** : Automatisation, déploiement et IaC
- **Plateforme** : Multiplateforme
- **Produit (matrice)** : Git / GitLab / GitHub / Gitea
- **Statut dans le pack** : Couvert

## 📚 Couverture dans le pack

Couvert — périmètre SaaS demandé : compte, clés SSH et secrets chiffrés GitHub Actions; aucun déploiement OS.

## 🧭 Utilisation

Cette fiche est le point d'entrée du logiciel : elle indique si le pack contient une procédure et renvoie vers elle. Pour une procédure pas à pas, ouvrir les fiches simples listées ci-dessous. Lorsque le statut est `Manquant`, aucune procédure dédiée n'existe encore dans le pack.

Fiches simples du guide : [Actions Secrets](</01-fiches-simples/transverses/cloud-saas/github/fiche-simple-github-actions-secrets>), [Cles SSH](</01-fiches-simples/transverses/cloud-saas/github/fiche-simple-github-cles-ssh>), [Compte](</01-fiches-simples/transverses/cloud-saas/github/fiche-simple-github-compte>).
