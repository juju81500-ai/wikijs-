# 📄 Apache

- **Catégorie** : Services Web et bases de données
- **Plateforme** : Linux / Windows
- **Produit (matrice)** : Apache / Nginx / IIS
- **Statut dans le pack** : Couvert

## 📚 Couverture dans le pack

Couvert — série par étape pour Debian 13 (prérequis, installation, configuration, sécurisation, recette, sauvegarde/restauration, mise à jour et retour arrière) ; [guide Apache HTTP Server sur Debian 13](/02-fiches-completes/debian/13/installation-deploiement/124-deploiement-apache-http-server-debian-13). IIS (Windows Server 2022) est traité dans sa propre série ; autres familles d'OS non traitées.
