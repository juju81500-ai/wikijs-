# 📄 mRemoteNG

- **Catégorie** : Scripting, développement et administration
- **Plateforme** : Windows
- **Produit (matrice)** : PuTTY / MobaXterm / mRemoteNG / Royal TS
- **Statut dans le pack** : Couvert — logiciel Windows : série dédiée Windows Client 11.

## 📚 Couverture dans le pack

Série Windows Client 11 couvrant prérequis, installation, connexions, sécurité, validation, sauvegarde/restauration et mise à jour. Une ancienne fiche ciblant Windows Server 2022 reste disponible séparément.

## 🧭 Utilisation

Windows Client 10 : [différences et limite de support de l’OS](/01-fiches-simples/windows/client-10/vie-du-logiciel/mremoteng/fiche-simple-vm-windows-10-mremoteng-differences) (note ciblée, sans recopier la série Client 11).

Cette fiche est le point d'entrée du logiciel : elle indique si le pack contient une procédure et renvoie vers elle. Pour une procédure pas à pas, ouvrir le guide ou la fiche liée ci-dessus. Lorsque le statut est `Manquant`, aucune procédure dédiée n'existe encore dans le pack.

Procédure pas à pas du pack : [mRemoteNG](/01-fiches-simples/logiciels/11-scripting-developpement-et-administration/fiche-simple-mremoteng).
