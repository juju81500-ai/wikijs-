# 📄 PuTTY

- **Catégorie** : Scripting, développement et administration
- **Plateforme** : Windows
- **Produit (matrice)** : PuTTY / MobaXterm / mRemoteNG / Royal TS
- **Statut dans le pack** : Couvert — Windows Client 11 et Debian 13 (putty-tools : plink, pscp, psftp, puttygen).

## 📚 Couverture dans le pack

Couvert — série Windows Client 11 (PuTTY graphique) et série Debian 13 pour les outils en ligne de commande `putty-tools` (`plink`, `pscp`, `psftp`, `puttygen`) : prérequis, installation, configuration, sécurité, validation, sauvegarde et mise à jour.

## 🧭 Utilisation

Windows Client 10 : [différences et limite de support de l’OS](/01-fiches-simples/windows/client-10/vie-du-logiciel/putty/fiche-simple-vm-windows-10-putty-differences) (note ciblée, sans recopier la série Client 11).

Cette fiche est le point d'entrée du logiciel : elle indique si le pack contient une procédure et renvoie vers elle. Pour une procédure pas à pas, ouvrir le guide ou la fiche liée ci-dessus. Lorsque le statut est `Manquant`, aucune procédure dédiée n'existe encore dans le pack.
