# 📄 rsync

- **Catégorie** : Sauvegarde, restauration et PRA / PCA
- **Plateforme** : Linux / Windows
- **Produit (matrice)** : rsync / Robocopy
- **Statut dans le pack** : Couvert

## 📚 Couverture dans le pack

Couvert pour rsync sur Debian 13 — [copie et sauvegarde de fichiers](/02-fiches-completes/debian/13/autres/92-sauvegarde-fichiers-rsync-debian-13). Une synchronisation miroir ne remplace pas une sauvegarde historisée.

Fiches simples du guide Debian 13 : [cadrer](/01-fiches-simples/debian/13/vie-du-logiciel/rsync/fiche-simple-vm-debian-13-rsync-cadrer-besoin), [préparer](/01-fiches-simples/debian/13/vie-du-logiciel/rsync/fiche-simple-vm-debian-13-rsync-installer-preparer), [prévisualiser](/01-fiches-simples/debian/13/vie-du-logiciel/rsync/fiche-simple-vm-debian-13-rsync-previsualiser), [copier sans suppression](/01-fiches-simples/debian/13/vie-du-logiciel/rsync/fiche-simple-vm-debian-13-rsync-copier-sans-suppression), [gérer les suppressions](/01-fiches-simples/debian/13/vie-du-logiciel/rsync/fiche-simple-vm-debian-13-rsync-gerer-suppressions), [valider/restaurer](/01-fiches-simples/debian/13/vie-du-logiciel/rsync/fiche-simple-vm-debian-13-rsync-valider-restaurer) et [retour arrière](/01-fiches-simples/debian/13/vie-du-logiciel/rsync/fiche-simple-vm-debian-13-rsync-retour-arriere).

## 🧭 Utilisation

Cette fiche est le point d'entrée du logiciel : elle indique si le pack contient une procédure et renvoie vers elle. Pour une procédure pas à pas, ouvrir le guide ou la fiche liée ci-dessus. Lorsque le statut est `Manquant`, aucune procédure dédiée n'existe encore dans le pack.

Procédure pas à pas du pack : [rsync](/01-fiches-simples/logiciels/07-sauvegarde-restauration-et-pra-pca/fiche-simple-rsync).
