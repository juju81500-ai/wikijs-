# 📄 Robocopy

- **Catégorie** : Sauvegarde, restauration et PRA / PCA
- **Plateforme** : Linux / Windows
- **Produit (matrice)** : rsync / Robocopy
- **Statut dans le pack** : Couvert

## 📚 Couverture dans le pack

Couvert pour Robocopy sur Windows Server 2022 — [copie et sauvegarde de fichiers](/02-fiches-completes/windows/server-2022/autres/93-copie-sauvegarde-fichiers-robocopy-windows-server-2022). Une copie miroir ne remplace pas une sauvegarde historisée.

## 🧭 Utilisation

Cette fiche est le point d'entrée du logiciel : elle indique si le pack contient une procédure et renvoie vers elle. Pour une procédure pas à pas, ouvrir le guide ou la fiche liée ci-dessus. Lorsque le statut est `Manquant`, aucune procédure dédiée n'existe encore dans le pack.

Procédure pas à pas du pack : [Robocopy](/01-fiches-simples/logiciels/07-sauvegarde-restauration-et-pra-pca/fiche-simple-robocopy).
