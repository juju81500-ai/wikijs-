# 📄 Exchange Online

- **Catégorie** : Messagerie et collaboratif
- **Plateforme** : Windows / Cloud
- **Produit (matrice)** : Exchange Server / Exchange Online
- **Statut dans le pack** : Cloud/SaaS — administration défensive

## 📚 Couverture dans le pack

Cloud/SaaS — administration défensive : série de fiches simples (domaine, MFA, SPF/DKIM/DMARC, rétention, recette). Pas de guide complet dédié ; aucune installation, service géré par l'éditeur.

## 🧭 Utilisation

Cette fiche est le point d'entrée du logiciel : elle indique si le pack contient une procédure et renvoie vers elle. Pour une procédure pas à pas, ouvrir le guide ou la fiche liée ci-dessus. Lorsque le statut est `Manquant`, aucune procédure dédiée n'existe encore dans le pack.
