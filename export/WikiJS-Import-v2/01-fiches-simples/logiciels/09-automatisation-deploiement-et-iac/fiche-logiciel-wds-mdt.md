# 📄 WDS + MDT

- **Catégorie** : Automatisation, déploiement et IaC
- **Plateforme** : Windows / Linux
- **Produit (matrice)** : WDS + MDT / FOG Project
- **Statut dans le pack** : Couvert — Windows Server 2022 (7 fiches). Windows Server 2025 non couvert : limite WDS documentée par Microsoft (voir Couverture).
- **Tags** : `logiciel`, `09-Automatisation-deploiement-et-IaC`, `couvert`

## 📚 Couverture dans le pack

Série Windows Server 2022 en 7 fiches : prérequis, installation, configuration, sécurisation, recette PXE, sauvegarde et maintenance. La [procédure historique WDS/MDT](/01-fiches-simples/logiciels/09-automatisation-deploiement-et-iac/fiche-simple-wds-mdt) reste disponible et n’est pas dupliquée. Windows Server 2025 : non couvert — Microsoft documente que le déploiement WDS depuis le `boot.wim` des médias Windows 11 et des versions futures de Windows Server est bloqué (PXE vers images personnalisées MDT/Configuration Manager non affecté) et recommande Configuration Manager ou MDT; aucune procédure 2025 n’est inventée ici. Le statut de support de MDT est à vérifier sur Microsoft Learn.
