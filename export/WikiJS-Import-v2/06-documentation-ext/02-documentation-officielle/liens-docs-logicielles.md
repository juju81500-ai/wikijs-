## Méthode de consultation

- Préférer une URL de version précise pour une fiche qui cible une version déterminée; `latest` peut changer après publication.
- Vérifier les notes de version, la matrice de compatibilité, les avis de sécurité et les prérequis d'OS avant de reprendre une commande.
- Pour un paquet distribué par Debian, Ubuntu ou RHEL, consulter également le suivi de sécurité du distributeur : les correctifs peuvent être rétroportés sans reprendre le numéro amont.
- Les sites communautaires et forums peuvent aider au diagnostic, mais ne remplacent pas la documentation du fournisseur ni un essai en environnement représentatif.
