# 📄 Exchange Server

- **Catégorie** : Messagerie et collaboratif
- **Plateforme** : Windows / Cloud
- **Produit (matrice)** : Exchange Server / Exchange Online
- **Statut dans le pack** : Partiel — Exchange Server Subscription Edition sur Windows Server 2025 et Exchange sur Windows Server 2022 couverts ; Exchange Online hors périmètre

## 📚 Couverture dans le pack

Partiel — Exchange Server sur Windows Server 2022 (procédures existantes) et une série de 7 fiches Exchange Server Subscription Edition sur Windows Server 2025 (prérequis, installation, connecteurs, certificats, DAG/sauvegarde, recette, CU/SU). Microsoft liste officiellement Exchange SE sur Windows Server 2025 dans sa matrice de support. Exchange Online n'est pas traité ici.
