# 📄 Microsoft RDS

- **Catégorie** : Poste de travail et VDI
- **Plateforme** : Windows
- **Produit (matrice)** : Microsoft RDS
- **Statut dans le pack** : Couvert — Windows Server 2022 et Windows Server 2025.
- **Tags** : `logiciel`, `13-Poste-de-travail-et-VDI`, `couvert`

## 📚 Couverture dans le pack

Les procédures RDS couvrent les prérequis, l’installation/configuration, la sécurisation, la recette, la sauvegarde/restauration et la maintenance sous Windows Server 2022, et sous Windows Server 2025 (prérequis et licences RDS CAL, installation GUI/PowerShell, TLS/comptes/pare-feu, recette, sauvegarde/restauration, mises à jour/rollback). Les fiches historiques d’activation RDP et de configuration restent disponibles dans le dossier RDS.

Fiches simples du guide : Windows Server 2022 — [prérequis et limites](../../Windows/Server-2022/Vie-du-logiciel/Remote-Desktop-Services/Fiche_Simple_-_Windows_Server_2022_RDS_Prerequis_Limites.md), [installer et configurer](../../Windows/Server-2022/Vie-du-logiciel/Remote-Desktop-Services/Fiche_Simple_-_Windows_Server_2022_RDS_Installer_Configurer.md), [sécuriser les accès](../../Windows/Server-2022/Vie-du-logiciel/Remote-Desktop-Services/Fiche_Simple_-_Windows_Server_2022_RDS_Securiser_Acces.md), [valider la recette](../../Windows/Server-2022/Vie-du-logiciel/Remote-Desktop-Services/Fiche_Simple_-_Windows_Server_2022_RDS_Valider_Recette.md), [sauvegarder et restaurer](../../Windows/Server-2022/Vie-du-logiciel/Remote-Desktop-Services/Fiche_Simple_-_Windows_Server_2022_RDS_Sauvegarder_Restaurer.md), [mettre à jour et revenir en arrière](../../Windows/Server-2022/Vie-du-logiciel/Remote-Desktop-Services/Fiche_Simple_-_Windows_Server_2022_RDS_Mise_A_Jour_Retour_Arriere.md)
