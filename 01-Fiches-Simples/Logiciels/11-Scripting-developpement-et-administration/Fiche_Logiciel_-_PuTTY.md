# 📄 PuTTY

- **Catégorie** : Scripting, développement et administration
- **Plateforme** : Windows
- **Produit (matrice)** : PuTTY / MobaXterm / mRemoteNG / Royal TS
- **Statut dans le pack** : Couvert — Windows Client 11 et Debian 13 (putty-tools : plink, pscp, psftp, puttygen).

## 📚 Couverture dans le pack

Couvert — série Windows Client 11 (PuTTY graphique) et série Debian 13 pour les outils en ligne de commande `putty-tools` (`plink`, `pscp`, `psftp`, `puttygen`) : prérequis, installation, configuration, sécurité, validation, sauvegarde et mise à jour.
