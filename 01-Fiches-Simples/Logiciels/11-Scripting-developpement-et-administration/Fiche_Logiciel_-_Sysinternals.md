# 📄 Sysinternals

- **Catégorie** : Scripting, développement et administration
- **Plateforme** : Windows
- **Produit (matrice)** : Sysinternals
- **Statut dans le pack** : Guide complet — acquisition vérifiée et diagnostic défensif sur Windows 11
- **Tags** : `logiciel`, `11-Scripting-developpement-et-administration`, `guide-complet`, `windows-11`, `defensif`

## 📚 Couverture dans le pack

Guide de diagnostic local limité à Process Explorer, Autoruns et Process Monitor. Les outils modifiant l'état système et les usages distants ne sont pas couverts.

## 🧭 Utilisation

Cette fiche est le point d'entrée du logiciel : elle indique si le pack contient une procédure et renvoie vers elle. Pour une procédure pas à pas, ouvrir le guide ou la fiche liée ci-dessus. Lorsque le statut est `Manquant`, aucune procédure dédiée n'existe encore dans le pack.
