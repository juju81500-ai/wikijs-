## 📚 Couverture dans le pack

Série de fiches de mise en œuvre, d’exploitation et de maintenance MECM/SCCM sous Windows Server 2022. Les matrices de prise en charge [[Glossary:SQL]], [[Glossary:ADK]]/WinPE et versions Configuration Manager doivent être vérifiées sur Microsoft Learn avant déploiement. Windows Server 2025 : la page Microsoft Learn « Supported site system servers » le liste comme hôte de site et de rôles de système de site; les conditions de version Configuration Manager, SQL et ADK sont à vérifier sur cette page. Aucune procédure spécifique à 2025 n’est fournie : les fiches 2022 ne doivent pas être transposées sans cette vérification.
