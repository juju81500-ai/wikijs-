## 📚 Couverture dans le pack

Couvert — le lot FreeIPA couvre :

- **Rocky Linux 9** : serveur FreeIPA ;
- **Debian 13** : client FreeIPA ;
- **Ubuntu 24-04** : client FreeIPA (paquet `freeipa-client`, compatibilité de version à vérifier).

Limites : procédures non testées ; clients Windows non couverts ; réplication et haute disponibilité (HA) non couvertes ; autres distributions non couvertes.
